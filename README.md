# 莒優探索館：失落的探索之星 V2

無登入、無個資蒐集。兩項任務：資優特質調查室、故障診斷工坊。

## 操作
電腦使用 WASD 或方向鍵，平板使用畫面方向鍵；拖曳環顧，點選展品。Quest Browser 使用進入 VR，左手搖桿移動，板機點選，亦可使用地面光圈傳送。房間邊界及主要展台有基本碰撞限制。

## 任務
任務 1：閱讀三件作品紀錄，逐一配對特質，完成最後身分判斷。
任務 3：閱讀三份檢測紀錄，從五個零件選擇三件，依供電、電路、傳動順序修復，按啟動測試。

## 驗證與限制
Three.js 0.170.0 CDN；需 HTTPS 與網路。V2 已上傳，尚待瀏覽器與 Quest 2 實機驗證。場景仍為程序式模型，尚未使用精緻外部模型或烘焙光影。重整重置進度。
