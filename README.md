# 莒優探索館：失落的探索之星

第一版：主展館、任務 01 誰是資優生、任務 03 修復發明機器。無登入、無資料蒐集。

## 部署
使用本專案儲存庫，將 index.html、museum.js 放在根目錄，Settings → Pages → Deploy from a branch → main / (root)。使用 HTTPS 網址開啟。Three.js 固定使用 0.170.0，由 jsDelivr CDN 載入，因此需要網路。亦可用本機 HTTP server 測試一般模式（例如 python -m http.server 8000）。

## 操作
一般模式：拖曳環顧、點選展品、底部按鈕切換展區。VR：Quest Browser 開啟 HTTPS 網址，按進入 VR，控制器射線指向物件並按板機。站點切換為瞬間傳送；不需要走動。兩個任務可重試，回主展館檢視星球。

## 驗收
1. 主展館能載入、環顧、切換兩展區。
2. 任務 01 複選三人後確認；少選時顯示提示，三人皆選才完成。特質不等同正式鑑定結果。
3. 任務 03 點零件、點插槽，錯誤不扣分；三件完成後啟動機器。
4. 回主展館確認兩星完成；一般模式重來按鈕清除本次進度。
5. Quest 2 實機驗證控制器射線、中文字大小、傳送位置、畫面流暢與退出 VR。

## 限制
目前為程序式 3D 美術原型，尚無專業手繪環景、外部 GLB 模型、烘焙光影或語音。程式已做 Node 語法檢查，但製作環境無法連線 CDN，未能執行瀏覽器渲染及 Quest 2 實機測試。GitHub Pages 須另行啟用及驗證。進度保存在本次頁面記憶體，重新整理即重置。
